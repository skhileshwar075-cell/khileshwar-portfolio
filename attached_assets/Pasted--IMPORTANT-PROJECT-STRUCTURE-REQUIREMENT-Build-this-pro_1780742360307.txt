# Architecture Requirements

Frontend and backend must be completely separated.

Frontend:

* React
* Vite
* Tailwind CSS
* shadcn/ui
* Framer Motion
* React Hook Form
* Zustand

Backend:

* Node.js
* Express.js
* PostgreSQL
* Prisma ORM
* JWT Authentication

# API Architecture

Backend must expose REST APIs.

Example:

```text
/api/auth
/api/projects
/api/skills
/api/experience
/api/education
/api/certificates
/api/blogs
/api/messages
/api/settings
/api/analytics
```

Frontend must consume APIs through service files.

Example:

```text
frontend/src/services/
├── authService.js
├── projectService.js
├── blogService.js
├── skillService.js
└── analyticsService.js
```
